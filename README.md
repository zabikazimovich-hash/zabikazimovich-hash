## 👋 Обо мне

Full stack разработчик из Узбекистана. Работаю на всём стеке: от баз данных и API до интерфейса, с которым взаимодействует пользователь. Специализируюсь на связке **сайт + Telegram-бот/Mini App на одной базе данных** — так продукт сразу доступен пользователю в двух привычных точках входа.

Сейчас в работе одновременно несколько продакшн-сервисов: такси-платформа, маркетплейс аренды недвижимости, AI-открытки. Открыт к фрилансу и постоянной работе.
